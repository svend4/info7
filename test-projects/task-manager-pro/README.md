## Database Schema Requirements

### Tables Needed

1. **profiles** - User profiles (extends Supabase auth.users)
   - id (uuid, FK to auth.users)
   - email
   - full_name
   - avatar_url
   - created_at
   - updated_at

2. **tasks** - Task items
   - id (uuid)
   - user_id (uuid, FK to profiles)
   - title (text)
   - description (text)
   - status (enum: todo, in_progress, completed)
   - priority (enum: low, medium, high)
   - due_date (timestamp)
   - category_id (uuid, FK to categories)
   - created_at
   - updated_at

3. **categories** - Task categories
   - id (uuid)
   - user_id (uuid, FK to profiles)
   - name (text)
   - color (text)
   - created_at

4. **tags** - Task tags
   - id (uuid)
   - user_id (uuid, FK to profiles)
   - name (text)
   - created_at

5. **task_tags** - Many-to-many relationship
   - task_id (uuid, FK to tasks)
   - tag_id (uuid, FK to tags)

### RLS Policies Required

- Users can only see their own data
- Users can CRUD their own tasks, categories, tags
- Profiles are readable by authenticated users (for collaboration)
